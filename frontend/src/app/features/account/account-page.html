El acceso está esbozado con ASP.NET Identity y JWT (POST /api/auth/register, POST /api/auth/login, GET /api/users/me). El formulario de login no forma parte de este esqueleto.

Las solicitudes de la clase gratis se listan con GET /api/inquiries/free-classes y el mismo JWT. La pantalla para revisarlas queda para cuando exista el login.
